    Documentation Index / 文書索引¶

    Summary: The index of all documents in this repository: policies (our position), specifications (rules to implement), decisions (why we chose), demos (records of what was actually done), status (milestone progress), hand-offs (requests to other teams), reviews (review records), and reference (external facts). A Mermaid diagram shows how a change flows through the process. 概要: このリポジトリのすべての文書の索引。方針（私たちの立場）、仕様（実装するルール）、決定（なぜ選んだか）、実証（実際にやったことの記録）、進捗（節目の進行状況）、引継ぎ（他のチームへの依頼）、レビュー（レビュー記録）、参考（外部事実）。Mermaid 図は、変更がプロセスを通る流れを示します。

    Jump: English · 日本語

    • Version / 版: 0.1 — 2026-11-05. Learned: without a single index page, it was unclear which folder to check for the latest milestone status or review records; putting everything in one place makes the documentation tree navigable. ／ 単一の索引ページが無ければ、最新の節目進捗やレビュー記録をどのフォルダで探すべきか分からず、文書ツリーのナビゲートが不可能になると分かった。
    • Normative for: every document under docs/, especially README.md files.
    • Related: ../README.md · site/index.html
