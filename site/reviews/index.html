    Review Records / レビュー記録¶

    Summary: Independent assessment of pull requests: each record is a dated file named YYYY-MM-DD_<em>rN.md, written by REV (Codex Astra). Reviews are linked from the PR and stored here for auditability. <strong>概要:</strong> プルリクエストの独立した評価：各記録は日付付きファイル、YYYY-MM-DD</em><Title>_rN.md の形式。REV（Codex Astra）が書く。レビューは PR からリンクされ、監査のためにここに保管される。</p> </blockquote> <p><strong>Jump:</strong> <a href="#english">English</a> · <a href="#japanese">日本語</a></p> <ul> <li>Version / 版: 0.1 — 2026-11-05. <strong>Learned:</strong> every PR gets an independent review, and the review must be kept as its own record so that what was checked, and why, can be read later. ／ すべての PR は独立したレビューを受け、何をなぜ確かめたかを後から読めるよう、レビューは独自の記録として残す必要があると分かった。</li> <li>Normative for: <a href="../spec/04_acceptance_tests/">SPEC-04 Acceptance Tests</a> review section, <a href="../decisions/ADR-04_AI_Autonomy_and_Roles/">ADR-04 AI Autonomy and Roles</a> review section.</li> <li>Related: <a href="../">../README.md</a> · <a href="../handoff/">handoff/</a> · <a href="../status/">status/</a></li> </ul> <hr /> <p><a id="english"></a></p> <h2 id="english">English<a class="headerlink" href="#english" title="Permanent link">¶</a></h2> <p><a href="#japanese">→ 日本語版へ</a></p> <h3 id="1-what-belongs-here">1. What belongs here<a class="headerlink" href="#1-what-belongs-here" title="Permanent link">¶</a></h3> <p>A <em>review record</em> documents REV's (Codex Astra) independent assessment of a pull request. This folder contains:</p> <table> <thead> <tr> <th>Type</th> <th>Naming convention</th> <th>Description</th> </tr> </thead> <tbody> <tr> <td>Review</td> <td><code>YYYY-MM-DD_<Title>_rN.md</code></td> <td>Review of PR #<N>; includes findings, approval/rejection, and suggestions.</td> </tr> </tbody> </table> <h3 id="2-review-format">2. Review format<a class="headerlink" href="#2-review-format" title="Permanent link">¶</a></h3> <p>A review record includes:</p> <ul> <li>Date of review</li> <li>PR title and number</li> <li>Scope of review (files changed, lines affected)</li> <li>Findings: security issues, bugs, style issues</li> <li>Approval status: approved / rejected / needs revision</li> <li>Suggested changes (if rejection or revision needed)</li> </ul> <h3 id="3-open-items-no-entries-yet--まだありません">3. Open items (no entries yet / まだありません)<a class="headerlink" href="#3-open-items-no-entries-yet--まだありません" title="Permanent link">¶</a></h3> <table> <thead> <tr> <th>Date</th> <th>Title</th> <th>PR</th> <th>Status</th> </tr> </thead> <tbody> <tr> <td>—</td> <td>—</td> <td>—</td> <td>—</td> </tr> </tbody> </table> <h3 id="4-creating-a-new-review-record">4. Creating a new review record<a class="headerlink" href="#4-creating-a-new-review-record" title="Permanent link">¶</a></h3> <ol> <li>Name the file <code>YYYY-MM-DD_<Title>_rN.md</code>.</li> <li>Link to the PR number in the header.</li> <li>Describe scope, findings, and approval decision.</li> <li>Link from the PR as "reviewed by REV (Codex Astra)".</li> </ol> <hr /> <p><a id="japanese"></a></p> <h2 id="日本語">日本語<a class="headerlink" href="#日本語" title="Permanent link">¶</a></h2> <p><a href="#english">→ To English</a></p> <h3 id="1-ここに属するもの">1. ここに属するもの<a class="headerlink" href="#1-ここに属するもの" title="Permanent link">¶</a></h3> <p>「レビュー記録」は REV（Codex Astra）がプルリクエストに対して行った独立した評価を文書化します。このフォルダには次が含まれます：</p> <table> <thead> <tr> <th>種別</th> <th>命名規則</th> <th>説明</th> </tr> </thead> <tbody> <tr> <td>レビュー</td> <td><code>YYYY-MM-DD_<Title>_rN.md</code></td> <td>PR #<N> のレビュー。調査結果、承認／拒否、提案を含む。</td> </tr> </tbody> </table> <h3 id="2-レビューの形式">2. レビューの形式<a class="headerlink" href="#2-レビューの形式" title="Permanent link">¶</a></h3> <p>レビュー記録には次が含まれます：</p> <ul> <li>レビュー日</li> <li>PR の題名と番号</li> <li>レビュー範囲（変更ファイル、影響行）</li> <li>調査結果：セキュリティ問題、バグ、スタイル問題</li> <li>承認ステータス：承認／拒否／修正必要</li> <li>提案される変更（拒否または修正が必要な場合）</li> </ul> <h3 id="3-未解決項目まだありません--no-entries-yet">3. 未解決項目（まだありません / no entries yet）<a class="headerlink" href="#3-未解決項目まだありません--no-entries-yet" title="Permanent link">¶</a></h3> <table> <thead> <tr> <th>日付</th> <th>タイトル</th> <th>PR</th> <th>ステータス</th> </tr> </thead> <tbody> <tr> <td>—</td> <td>—</td> <td>—</td> <td>—</td> </tr> </tbody> </table> <h3 id="4-新しいレビュー記録をつくるには">4. 新しいレビュー記録をつくるには<a class="headerlink" href="#4-新しいレビュー記録をつくるには" title="Permanent link">¶</a></h3> <ol> <li>ファイル名を <code>YYYY-MM-DD_<Title>_rN.md</code> にする。</li> <li>ヘッダに PR 番号へリンクする。</li> <li>範囲、調査結果、承認決定を記述する。</li> <li>PR から「REV（Codex Astra）レビュー済み」としてリンクする。</li> </ol> <hr /> <h2 id="glossary--用語">Glossary / 用語<a class="headerlink" href="#glossary--用語" title="Permanent
